# ✅ Чеклист деплоя

Используйте этот чеклист для проверки готовности к деплою.

## 📋 Pre-deployment

### Код
- [ ] Все тесты проходят
- [ ] Нет ошибок линтера
- [ ] Код закоммичен и запушен в GitHub
- [ ] README.md обновлен
- [ ] Все секреты не включены в код

### Frontend
- [ ] Все зависимости установлены (`npm install`)
- [ ] Проект собирается (`npm run build`)
- [ ] Переменные окружения настроены
- [ ] API URL правильный
- [ ] Нет ошибок в консоли браузера

### Backend
- [ ] Все зависимости установлены (`pip install -r requirements.txt`)
- [ ] Сервер запускается локально
- [ ] API документация доступна (`/docs`)
- [ ] Health check работает (`/health`)
- [ ] Переменные окружения настроены
- [ ] База данных настроена

### База данных
- [ ] PostgreSQL доступна
- [ ] Миграции применены (если есть)
- [ ] Подключение тестировано

## 🚀 Деплой Frontend (Vercel)

- [ ] Vercel аккаунт создан
- [ ] Репозиторий подключен к Vercel
- [ ] Root Directory: `frontend`
- [ ] Build Command: `npm run build`
- [ ] Output Directory: `build`
- [ ] Environment Variables:
  - [ ] `REACT_APP_API_URL` установлен
- [ ] Деплой успешен
- [ ] Сайт доступен и работает

## 🚀 Деплой Backend (Railway)

- [ ] Railway аккаунт создан
- [ ] Репозиторий подключен
- [ ] PostgreSQL база создана
- [ ] Environment Variables:
  - [ ] `DEEPSEEK_API_KEY` установлен
  - [ ] `DATABASE_URL` установлен (автоматически)
  - [ ] `FRONTEND_URL` установлен
- [ ] Деплой успешен
- [ ] API доступен и работает

## 🐛 Troubleshooting

Если что-то не работает:

1. **Проверьте логи:**
   - Vercel: Dashboard → Logs
   - Railway: Dashboard → Logs

2. **Проверьте переменные окружения:**
   - Все ли они установлены?
   - Правильные ли значения?

3. **Проверьте подключение:**
   - Frontend может достучаться до Backend?
   - Backend может достучаться до БД?

4. **Проверьте квоты:**
   - Не превышены ли лимиты на платформах?
