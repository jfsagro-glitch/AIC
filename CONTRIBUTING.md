# 🤝 Руководство по внесению вклада

Спасибо за интерес к проекту AI Залоговик!

## 🚀 Начало работы

1. Fork репозитория
2. Создайте ветку для вашей функции (`git checkout -b feature/amazing-feature`)
3. Закоммитьте изменения (`git commit -m 'Add amazing feature'`)
4. Push в ветку (`git push origin feature/amazing-feature`)
5. Откройте Pull Request

## 📝 Стандарты кода

### Python (Backend)
- Используйте `black` для форматирования
- Следуйте PEP 8
- Типизация с помощью type hints
- Документация docstrings

### TypeScript/React (Frontend)
- Используйте ESLint и Prettier
- Компоненты в PascalCase
- Файлы в camelCase
- Используйте функциональные компоненты

## 🧪 Тестирование

Перед отправкой PR убедитесь, что:
- [ ] Код работает локально
- [ ] Нет ошибок линтера
- [ ] Добавлены тесты для новой функциональности
- [ ] Документация обновлена

## 📋 Формат коммитов

Используйте понятные сообщения коммитов:
- `feat: добавлена функция оценки гостиниц`
- `fix: исправлена ошибка расчета NOI`
- `docs: обновлена документация API`
- `refactor: оптимизирован модуль расчетов`

## ✅ Pull Request процесс

1. Обновите вашу ветку до последней версии main
2. Убедитесь, что все тесты проходят
3. Добавьте описание изменений
4. Привяжите к issue, если есть

## 🐛 Сообщение об ошибке

При сообщении об ошибке укажите:
- Описание проблемы
- Шаги для воспроизведения
- Ожидаемое поведение
- Версия Python/Node
- Скриншоты (если применимо)

## 💡 Предложения

Мы приветствуем предложения! Откройте Issue с пометкой `enhancement`.

## 📄 Лицензия

Внося вклад, вы соглашаетесь с тем, что ваш вклад будет под той же лицензией, что и проект.
